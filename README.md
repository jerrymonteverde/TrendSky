# TrendSky

**Discover what's rising.**

TrendSky is an open-source social intelligence and predictive
analytics platform inspired by Google Trends.

Built using public Bluesky data, TrendSky explores emerging
conversations, analyses historical activity, compares topics,
and uses Machine Learning to investigate future trends.

## Features

Planned capabilities include:

- Real-time Bluesky trend discovery
- Interest over time
- Topic comparison
- Predictive analytics
- Machine Learning forecasting
- Natural Language Processing
- Distributed data processing
- Interactive visualisations

## Technology Stack

- Next.js
