# Portfolio case study — foundation

This is Jerry Monteverde's personal project, not a statement of employment experience.

Problem: build a transparent way to investigate public Bluesky conversations without confusing observed posts with search interest or complete-network activity.

Milestone 1 hypothesis: a small, well-separated web/API/database foundation can support later collection and analytical workflows while showing missing data honestly. The implemented work is software architecture, visual design, typed contracts, schema migration, automated verification and deployment configuration.

No source dataset, exploratory result, engineered predictive feature, model accuracy, ranking experiment or performance improvement is reported. The engineering report records actual foundation checks. Future analytical case studies must include a research question, source coverage, hypothesis, method, EDA, features, baselines, chronological evaluation, measured results and limitations.
