# Milestone 1 engineering report

Date: 2026-10-24. Branch: `develop`. Scope: application foundation only.

## Outcome

Implemented the original TrendSky application with its mandatory Blue Sky palette and locally bundled Ubuntu Normal typography, responsive routes, search navigation, light/dark themes, API contracts, database model/migration and container/CI definitions. The application build and local functional checks pass. Full milestone acceptance remains blocked by Docker permissions; PostgreSQL connectivity and container startup are not claimed as verified.

## Implemented features

- Homepage: prominent topic search, transparent trending empty state, concise feature introductions and coverage explanation.
- `/explore`: URL-preserved keyword/hashtag/phrase input and clearly disabled historical filters; no unimplemented chart or comparison is passed off as working.
- `/trending`, `/predictions`, `/about`: informative states describing collection, model availability and limits.
- Keyboard navigation, mobile menu, focus styles, search validation, persistent themes, 404 and error boundaries.
- Server-to-server API communication with timeout and safe unavailable state.
- FastAPI versioned liveness/readiness/summary endpoints, OpenAPI, explicit CORS, bounded in-process rate limiter and safe database errors.
- SQLAlchemy source registry and reversible seeded Alembic migration. Registry creation is distinguished from collection start.
- PostgreSQL bootstrap with a restricted role, migration startup gate, persistent volumes, service health checks, log rotation, resource caps and optional Caddy HTTPS.
- Dependency locks, deterministic tests, CI definitions, runbook and reproducible smoke script.
