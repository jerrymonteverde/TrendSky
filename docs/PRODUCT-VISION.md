# Product vision

TrendSky helps people investigate how public Bluesky conversations develop: what is rising, how topics compare and what evaluated models may suggest about future activity. The tagline is “Discover what's rising.”

The primary task is a topic search with shareable context. The interface favours readable data, whitespace, restrained colour and clear coverage over a crowded admin dashboard. Mobile is a primary layout.

Milestone 1 provides navigation, search URL handling, themes and infrastructure. Every analytical feature is deferred. No synthetic topics are shown as real trends. No claim is made about Google searches, private data or the entire internet.
